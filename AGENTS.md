# Repository guidance

Use `.agents/skills/figma-carousel/SKILL.md` for template-based carousel creation and revision.

- Keep configuration reusable. Never commit private Figma IDs, credentials, personal settings, run records, downloaded fonts or photos.
- Preserve master templates and edit verified output copies only.
- User instructions and local settings determine template names, fonts, sizes and line limits; do not impose the original test template.
- Follow current connected Figma API instructions.
- Validate JSON and relative Markdown links after changes and report actual verification limits.
